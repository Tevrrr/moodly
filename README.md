# Mood Tracker

Простое Next.js приложение для ежедневного отслеживания настроения.

## Что умеет

- выбор настроения за текущий день;
- короткая заметка до 280 символов;
- сохранение записей в `localStorage`;
- недельная сводка и серия дней;
- история с удалением отдельных записей.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Проверка

```bash
npm run lint
npm run build
```
